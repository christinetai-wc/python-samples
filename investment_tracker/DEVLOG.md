# DEVLOG - 投資理財資金分配追蹤系統

### 2026-03-10 選擇權無資金來源自動按比例分攤
- 選擇權若未填資金來源，按各股票剩餘預算比例分攤到多檔股票
- 保守型、樂透型也能顯示選擇權的保證金和買方成本
- 新增交易紀錄：VOO 1股 $620、NVDA buy call $180

### 2026-03-10 水平與垂直配置排序統一
- 兩張圖表共用 `sorted_chart` 排序邏輯（保守型→樂透型→進攻型）
- Treemap 加 `sort=False` 避免按 value 大小重排

### 2026-03-10 圖表與輸入全面重構
- **水平配置**：改用 Treemap 顯示資金分配，比例可調（預設 10/10/80）
- **垂直配置**：堆疊長條圖擴展到所有類型（不只進攻型），4 層：已買入/賣方保證金/買方成本/待部署
- **已實現損益**：賣股獲利加回總預算池（平均成本法）
- **選擇權買方成本**：新增 `calculate_option_buy_cost()` 函數，圖表和總覽都顯示
- **交易輸入**：改為表單 + 可點選表格（click-to-edit），取代舊的 data_editor
- **投資計畫簡化**：移除按月分類型投入，改為總額 × 水平比例自動分配
- **移除驗證**：移除月度檢查、下限檢查、比例檢查等不需要的驗證函數
- **向後相容**：自動 drop 舊 CSV 的 `投資類型` 欄位
